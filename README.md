## 🌟 Features

- 🕹️ Product categories showcase (consoles, games, phones, PCs, accessories, gift cards)
- ⭐ Customer reviews section
- 🖼️ Image gallery / showcase
- 📩 Contact form
- 🧭 Smooth scroll navigation
- 📱 Fully responsive design for all devices

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📂 Getting Started

```bash
git clone https://github.com/Tyholaz/Game-Store-landing-page.git
cd Game-Store-landing-page
```
Open `index.html` in your browser — no build step required.
